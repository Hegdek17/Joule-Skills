# Timesheet-Tracker
Joule Skill to easily track time spent on activities through the week resulting in a consolidated weekly output.
Simply begin by asking Joule to log your time by giving the Day/Date, Customer name or activity identifier, hours spent (in multiples of 0.5 hours), Activity Type as CF (Customer Facing) or NCF (Non Customer Facing) and Opp. ID. The Opp. ID is not mandatory at this point.
This Joule skill can log new entry, update existing entry and provide reports of various kinds based on the data available.
